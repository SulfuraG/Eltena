# 現状の制限

- 未完成のソフトウェアの技術資料です。サーバーパック、安定版リリース、移行ツールではありません。
- サーバーはPure Paper / Java 21、NeoForgeはクライアント側です。サーバーMod共存の実装ではありません。
- 魔法は現行機能として未実装。LifeAction系を収録・実装済みとして扱いません。
- Addonにはモックデータや段階移行用の表示モデルが残ります。画面が存在することは機能完成を意味しません。
- EffectのCatmull-Romスプライン評価、EffectCoreのentity-ref look-at解決などにTODOが残ります。
- Coreには旧装備IDの設定例や旧表現が残っています。現行サーバーにMod装備や旧成長仕様を採用する宣言ではありません。
- CoreのMythicMobsビルド依存は別途必要です。外部有料プラグインや第三者jarは同梱しません。
- 元のフォント画像と咆哮音は収録しますが、BGM3点とレベルアップ音は含みません。ゲーム内動作の再現は目的ではありません。
- 自動テストのないモジュールに対するGradle build成功は、ゲーム内動作の合格を意味しません。
- Windowsのソースを公開準備の基準にしています。Macの最新配置物との対応は未確認です。
- 既存のワールド・プレイヤーデータを使う検証、サーバー起動、クライアント起動、Productionへの配備は行っていません。

ライブアセットの実装済み範囲はゲーム中の音声転送・再生です。画像・モデル・フォントなど音声以外の転送・更新は実装していません。音声の具体的な転送方式・キャッシュ・操作と未実装範囲は [音声実装資料](SOUND_IMPLEMENTATION.md) を参照してください。

この資料の目的は完成品の動作再現ではなく、実際に作った技術を読むことです。元の参照関係はdocs/reference-resourcesに保持しています。
